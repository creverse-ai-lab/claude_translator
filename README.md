# claude_translator

Claude Code가 답변을 터미널에 **표시하기 직전**에 가로채서, 로컬 Ollama의
`gemma4:e2b`로 다시 쓰는 훅입니다.

화면에 보이는 글자만 바뀝니다. 저장되는 대화 기록과 Claude가 읽는 내용은
그대로입니다.

## 설치

필요한 것: macOS/Linux, `python3`(표준 라이브러리만 사용), [Ollama](https://ollama.com), Claude Code 2.1.235 이상.

```bash
git clone <이 저장소> claude_translator
cd claude_translator
./install.sh
```

`install.sh` 가 하는 일:

1. python3 / ollama 확인, `config.json` 에 적힌 모델이 없으면 `ollama pull`
2. `~/.claude/settings.json` 에 `MessageDisplay` 훅을 **병합** 등록
   — 기존에 있던 다른 훅과 설정은 건드리지 않고, 수정 전 백업을
   `settings.json.before-translator.bak` 으로 남깁니다
3. `/translator` 슬래시 커맨드를 `~/.claude/commands/` 에 설치
4. 번역 상태를 `on` 으로 설정

재실행해도 중복 등록되지 않습니다(기존 항목을 교체). 저장소를 다른 위치로
옮겼으면 `install.sh` 를 다시 실행하면 경로가 갱신됩니다.

제거는 `./uninstall.sh` — 훅 등록, 슬래시 커맨드, 상태 파일만 지우고
저장소와 다른 훅은 그대로 둡니다.

## 어떻게 동작하는가

Claude Code 2.1.235의 `MessageDisplay` 훅을 사용합니다.

1. Claude가 답변을 스트리밍하는 동안, 완성된 줄이 생길 때마다 훅이 실행됩니다
   (약 100ms 간격, 최대 3개 동시).
2. 중간 실행은 화면에 빈 문자열을 내보냅니다. 즉 스트리밍 중에는 아무것도
   보이지 않습니다.
3. 마지막 실행에서 지금까지 모인 조각을 전부 합쳐 하나의 완성된 답변을 만듭니다.
4. 그 답변을 조각으로 잘라 Ollama에 병렬로 보내고, 결과를 순서대로 이어붙여
   한 번에 화면에 출력합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `hooks/translate_display.py` | 훅 본체 |
| `hooks/prompt.en.md` | 영어 프롬프트 (기본값) |
| `hooks/prompt.ko.md` | 한국어 프롬프트 (내용 동일, 비교용) |
| `config.json` | 모델, 조각 크기, 타임아웃 등 |
| `install.sh` / `uninstall.sh` | 설치·제거 스크립트 |
| `.claude/settings.json` | 이 프로젝트에만 훅 등록 |

## 설정값

| 키 | 기본값 | 뜻 |
|---|---|---|
| `enabled` | `true` | `false`로 두면 원문을 그대로 통과시킵니다 |
| `model` | `gemma4:e2b` | Ollama 모델 이름 |
| `min_chars` | `200` | 이보다 짧은 답변은 손대지 않습니다 |
| `max_chunk_chars` | `1200` | 조각 하나의 최대 길이 |
| `min_chunk_chars` | `400` | 이보다 짧은 마지막 조각은 앞 조각에 붙입니다 |
| `parallel_chunks` | `3` | 동시에 처리할 조각 수 |
| `min_output_ratio` | `0.6` | 결과가 원문의 60% 미만이면 실패로 봅니다 |
| `max_retries` | `1` | 실패 시 재시도 횟수 |
| `mark_fallback` | `true` | 원문을 그대로 둔 부분에 사유를 표시합니다 |
| `collect_actions` | `true` | "~하세요", "~필요합니다" 문장을 문서 끝에 복사해 모아줍니다 |
| `actions_min` | `2` | 행동 문장이 이 개수 이상일 때만 모음 블록을 붙입니다 |
| `mark_chunks` | `false` | 조각 경계에 `---` 를 그립니다 |
| `keep_original` | `true` | 비교 모드. Claude 원문과 다시 쓴 글을 위아래로 나눠서 둘 다 보여줍니다 |
| `prompt_file` | `prompt.en.md` | 쓸 프롬프트 파일. `prompt.ko.md` 로 바꿔 비교할 수 있습니다 |
| `debug` | `true` | `~/.claude/message-display-translator/` 에 로그와 조각 덤프를 남깁니다 |

모든 키는 환경변수로도 덮어쓸 수 있습니다. 예: `CT_MODEL=gemma4:e4b`,
`CT_ENABLED=0`.

## 내용을 잃지 않기 위한 장치

작은 모델은 문장을 통째로 빠뜨립니다. 그래서 세 겹으로 막아뒀습니다.

1. **코드 보호** — ```` ``` ```` 블록과 백틱 안의 글자는 `[[CODE_0]]` 같은
   자리표시자로 바꿔서 보냅니다. 모델이 코드를 건드릴 수 없습니다.
2. **조각 검증** — 조각마다 결과를 검사합니다. 자리표시자가 사라졌거나 길이가
   원문의 60% 아래면 실패로 보고 다시 시도합니다.
3. **원문 대체** — 재시도까지 실패하면 그 조각은 Claude 원문 그대로 둡니다.
   구멍이 뚫리는 대신 번역이 안 된 채로 남습니다.

여기에 더해, 조각 내기 자체가 글자를 잃거나 복제하지 않았는지 매번 대조합니다.
어긋나면 조각 내기를 포기하고 통째로 한 번에 처리합니다.

스트리밍 조각은 `~/.claude/message-display-translator/buffer/` 에 메시지별로
모았다가 마지막에 합칩니다. 아직 처리 중인 조각이 남아 있을 수 있어서 이 폴더는
바로 지우지 않고, 10분이 지난 것만 정리합니다.

## 기계적 치환은 파이썬에서

`N배 줄었다` 는 한국어에서 "N분의 1이 되었다"로도 "N만큼 줄었다"로도 읽힙니다.
이걸 프롬프트로 시켜봤더니 `gemma4:e2b` 가 두 번 다 실패했습니다.

| 시도 | 결과 |
|---|---|
| 프롬프트에 규칙만 씀 | `쿼리가 3배 줄었습니다` 를 그대로 통과시킴 |
| 프롬프트에 금지 예시까지 씀 | `501번이 6번으로 줄어듭니다` → `501분의 6으로 줄어듭니다` 로 **왜곡** |

금지 예시 안에 패턴을 적어주면 모델이 그 패턴을 배워버립니다. 그래서 이 규칙은
프롬프트에서 빼고 파이썬 정규식으로 옮겼습니다.

```python
SHRINK_RE = re.compile(r"(\d+)배(\s*)(줄|감소|작아|축소|낮아|짧아|적어)")
```

| 입력 | 출력 |
|---|---|
| `쿼리가 3배 줄었습니다` | `쿼리가 3분의 1로 줄었습니다` |
| `지연이 10배 감소했습니다` | `지연이 10분의 1로 감소했습니다` |
| `쿼리가 1번으로 줄어듭니다` | 그대로 (`배`가 없음) |
| `501번이 6번으로 줄어듭니다` | 그대로 (`배`가 없음) |
| `처리량이 3배 늘었습니다` | 그대로 (늘어난 것은 애매하지 않음) |

여기에 숫자 보존 검사도 추가했습니다. 원문에 있던 숫자가 결과에서 사라지면
그 조각은 실패로 보고 재시도합니다.

## 프롬프트는 짧게, 규칙은 파이썬으로

작은 모델은 프롬프트가 길어질수록 지시를 놓칩니다. 실제로 프롬프트가
5,459자였을 때, 프롬프트 안에 예시로 적어둔 문장까지 그대로 통과시켰습니다.
그래서 원칙을 바꿨습니다.

> 정답이 하나로 정해지는 규칙은 전부 파이썬 정규식으로. 프롬프트에는 판단이
> 필요한 것만 남긴다.

프롬프트는 1,124자(영어판)입니다. 파이썬이 모델보다 먼저 처리하는 것:

| 종류 | 예 |
|---|---|
| 이중 피동 | `보여집니다` → `보입니다`, `되어집니다` → `됩니다` |
| `N배 줄었다` | `12배 줄었다` → `12분의 1로 줄었다` (`배` 없으면 안 건드림) |
| 불필요한 대명사 | `당신의`, `우리는`, `우리가` 삭제 |
| 고정 번역투 | `~인 것으로 확인됩니다` → `~입니다`, `~수 있을 것입니다` → `~수 있습니다`, `개선이 이루어졌습니다` → `개선했습니다`, `검증 작업을 수행할 예정입니다` → `검증할 예정입니다` |
| 정보 없는 첫 문장 | `조사해봤습니다. 결론부터 말하면` 삭제 후 결론부터 시작 |

정규식이라 모델이 놓칠 수 없고, 토큰도 시간도 들지 않습니다.

**행동 항목 모음.** `~하세요`, `~필요합니다`, `~권합니다`, `~주십시오` 문장이
2개 이상이면 번역 후 문서 끝에 그대로 복사해 모아줍니다. 요약이 아니라
복제라서 본문에도 남습니다. 코드 블록 안은 긁지 않습니다. `~해야 합니다`가
행동이 아닌 설명 문장까지 잡는 오탐이 있습니다(`actions_min`, 
`collect_actions`로 조절).

## 비교 모드

`config.json` 의 `keep_original` 이 `true` 면 원문과 결과를 둘 다 보여줍니다.

```
── 전 · Claude 원문 ────────────────────────────

커넥션 풀 고갈로 인한 요청 타임아웃 다발.

── 후 · gemma4:e2b ─────────────────────────────

커넥션 풀이 고갈되어 요청이 시간 초과되는 일이 많이 발생했습니다.
```

번역 결과만 보고 싶으면 `false` 로 바꾸거나 `CT_KEEP_ORIGINAL=0 claude` 로
실행하세요.

## 성능 (실측)

`gemma4:e2b`, Apple Silicon 기준입니다.

| 원문 길이 | 조각 수 | 걸린 시간 | 프롬프트 |
|---|---|---|---|
| 360자 | 1 | 28.1초 | 구판 5,459자 |
| 360자 | 1 | 18.8초 | 압축판 1,124자 |
| 977자 | 4 | 42.8초 | 압축판 1,124자 |

이 시간 동안 화면에는 아무것도 보이지 않다가 한 번에 나타납니다. 훅 타임아웃은
180초로 잡아뒀습니다.

## 자원 사용량 (실측, 24GB Mac)

| 항목 | 크기 |
|---|---|
| 이 프로젝트 (코드) | 92KB |
| `gemma4:e2b` 디스크 | 7.2GB |
| 모델 상주 RAM (로드 시) | **6.8~7.3GB** (통합 메모리, `top`의 RSS에는 안 잡힘) |
| 추론 중 추가 사용 | 거의 없음 (num_ctx 4096 기준, 상주분에 포함) |

동작 방식: 첫 번역 요청에서 모델이 RAM에 올라가고, `keep_alive`(기본 30분)
동안 상주하다가 반납됩니다. **`/translator off` 상태에서는 모델을 아예
호출하지 않으므로 RAM을 쓰지 않습니다** (이미 로드돼 있던 것은 keep_alive
만료 때 내려감. 즉시 내리려면 `ollama stop gemma4:e2b`).

RAM이 아쉬우면 `config.json` 의 `keep_alive` 를 `"5m"` 이나 `"0"` 으로
줄이세요. 대신 다음 답변 때 콜드 로드 시간(수 초~십수 초)이 추가됩니다.

## 켜고 끄기 — 스킬처럼 쓰기

훅은 항상 실행되지만, 상태 파일을 먼저 보고 꺼져 있으면 원문을 그대로
통과시킵니다 (모델 호출 없음, 지연 없음). 그래서 세션 중에 즉시 켜고 끌 수
있습니다.

| 방법 | 명령 |
|---|---|
| 세션 안에서 | `/translator on`, `/translator off`, `/translator status`, `/translator` (토글) |
| 터미널에서 | `python3 hooks/translate_display.py --on` (`--off`, `--toggle`, `--status`) |

상태는 `~/.claude/message-display-translator/state` 에 저장되며 모든 세션에
공통 적용됩니다. 변경은 다음 답변 표시부터 반영됩니다. 상태 파일이 없으면
`config.json` 의 `enabled` 값을 따릅니다.

"평소엔 끄고 필요할 때만 켜기"로 쓰려면 한 번만 `/translator off` 해두면
됩니다.

## 설치 상태

**전역 설치 완료.** `~/.claude/settings.json` 의 `hooks` 는 지금 이 훅 하나만
가지고 있습니다. 모든 세션에 적용됩니다.

```json
"MessageDisplay": [
  {
    "hooks": [
      {
        "type": "command",
        "command": "python3 /Users/cyyoon/dev/personal_program/claude_translator/hooks/translate_display.py",
        "timeout": 180
      }
    ]
  }
]
```

같이 바뀐 것:

- 기존 orca 훅 10개(`UserPromptSubmit`, `Stop`, `StopFailure`, `SubagentStart`,
  `SubagentStop`, `TeammateIdle`, `PreToolUse`, `PostToolUse`,
  `PostToolUseFailure`, `PermissionRequest`)를 전부 제거했습니다.
- orca **상태줄**(`statusLine`)은 그대로 뒀습니다. 훅이 아니라 화면 아래
  상태 표시줄이라 지우면 표시줄이 사라집니다.
- 되돌리려면 `~/.claude/settings.json.before-translator.bak` 을
  `~/.claude/settings.json` 으로 덮어쓰면 됩니다.

되돌리는 명령:

```bash
cp ~/.claude/settings.json.before-translator.bak ~/.claude/settings.json
```

잠깐 끄고 싶을 때는 파일을 건드리지 말고 환경변수를 쓰세요.

```bash
CT_ENABLED=0 claude
```

## 규칙별 상태

프롬프트 규칙은 `hooks/prompt.en.md` 에 있습니다. 규칙 2는 판단이 필요한
"애매한가?" 대신, 패턴을 훑어서 바꾸는 치환 규칙 5개로 내렸습니다.

| 규칙 | 상태 |
|---|---|
| 1. 용어를 일반적인 말로 | 됨 |
| 2 · S1. 지시어 → 실제 대상 | 절반 — `이 값` → `커넥션 풀 최대치인 20` 은 성공, `해당` 으로 바꾸기만 하는 경우도 있음 |
| 2 · S2. 빠진 주어/목적어 채우기 | **안 됨** — `실패하면 재시도합니다` 를 그대로 통과 |
| 2 · S3. 수식어 위치 바로잡기 | **안 됨** — `새로운 사용자 인증 방식` 을 그대로 통과 |
| 2 · S4. 이중 부정 → 긍정 | 미검증 |
| 2 · S5. `A와 B의 C` 명확히 | 미검증 |
| 3. 압축된 표현 풀기 | 됨 — 조사 없이 명사 3개 이상 이어질 때 작동 |
| 4. 생략 금지 | 됨 |
| 5. 원문 구조 유지 | 됨 — 표, 목록, 제목 모두 보존 |
| 6. 예시 그대로 노출 | 됨 |
| 7. 의견 추가 금지 | 됨 |
| 8. 요약 금지 | 됨 |

남은 왜곡 두 가지입니다.

- `미봉책` → `임시방편` 처럼 단어를 비슷한 다른 단어로 바꿉니다. 영어판과
  한국어판 모두 그렇습니다.
- 문장을 매끄럽게 하려고 `이것은`, `이는`, `해당` 같은 지시어를 새로 넣습니다.
  S1과 정반대 방향입니다.

## 영어 프롬프트 vs 한국어 프롬프트

같은 내용을 두 언어로 써서 같은 입력에 돌린 결과입니다. 속도는 차이가 없었습니다
(43.8초 대 43.5초).

| 항목 | 영어 프롬프트 | 한국어 프롬프트 |
|---|---|---|
